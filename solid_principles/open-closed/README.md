# Open-Closed Principle (OCP)

## Definition

The Open-Closed Principle is one of the five SOLID design principles.

It states that:

> Software entities should be open for extension, but closed for modification.

## Main Idea

Software components should allow new functionality to be added without modifying existing code.

## Key Points

- Allow new behaviors through extension.
- Avoid unnecessary modifications to existing code.
- Use abstractions to reduce coupling.
- Use polymorphism to support different implementations.

## Important

OCP does not mean that existing code can never be modified.

It means that software should be designed to accommodate new functionality with minimal changes to existing components.
